- **Sobre ella**: quién la emitió, cuándo, hasta cuándo vale y por qué
  registry llegó.
- **Estado** <Mark n={1} />: cómo está, según lo último que dijo su emisor.
  **Comprobar el estado** <Mark n={2} /> vuelve a preguntarlo ahora.
- **Lo que dice** <Mark n={3} />: cada dato que contiene. Cuando enseñas la
  credencial solo salen los datos que se piden, nunca todos salvo que se pidan
  todos.
- **Quitar de este wallet** <Mark n={4} />: la saca para siempre, después de
  volver a preguntarte.

## Cómo está una credencial

| En la tarjeta | Qué significa |
| --- | --- |
| **Válida** | Vale: puedes enseñarla. |
| **Suspendida** | El emisor la ha pausado, por ahora. El wallet no la ofrece y quien la compruebe la rechaza. Puede rehabilitarse. |
| **Revocada** | El emisor la ha retirado para siempre. Solo el emisor puede darte una nueva. |

El wallet comprueba cómo está cada una al abrirlo, como mucho cada diez
minutos, y siempre que pulsas la flecha circular de **Inicio**.

<Aside type="caution">
Quitar una credencial no se puede deshacer: no queda ninguna copia, y solo su
emisor puede volver a dártela. Una copia de seguridad hecha antes (**Perfil →
Copia de seguridad**) la conserva.
</Aside>
