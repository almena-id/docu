import ErrorCodes from '@docs/ErrorCodes.astro';

Cuando la API rechaza una petición, su cuerpo dice por qué con un código:

```json
{ "detail": "category_in_use" }
```

Actúa sobre el código, no solo sobre el estado: un mismo estado tiene muchas
razones. Esta página se genera a partir del documento OpenAPI de la API, así
que el significado de cada código está en inglés, con las palabras de la
propia API.
