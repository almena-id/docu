Cada página de aquí se genera a partir de los propios proyectos, no se
escribe a mano: cuando cambia el código, la referencia se regenera con él.

- [API](/reference/api/): cada operación de la API de Almena Registry —sus
  parámetros, cuerpo, respuestas y rechazos— y cada esquema, a partir de su
  documento OpenAPI. En inglés, como la propia API.
- [CLI](/reference/cli/): cada orden de `almena` y sus opciones, a partir de
  la ayuda del propio binario. En inglés, como la propia CLI.
- [Errores](/es/reference/errors/): cada código con el que la API rechaza algo,
  qué significa y qué operaciones lo devuelven.
