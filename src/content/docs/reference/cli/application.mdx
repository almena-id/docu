## `almena application list`

List the applications received (submitted or decided), newest first

```text
Usage: almena application list [OPTIONS]
```

```text
Options:
      --issuer <ISSUER>
          Only those sent to this issuer (its id)

      --limit <LIMIT>
          Items per page (1–100)
          
          [default: 20]

      --cursor <CURSOR>
          Start after this cursor (a page's `next_cursor`)

      --all
          Follow `next_cursor` until the last page
```

## `almena application file`

Save a file the holder uploaded

```text
Usage: almena application file [OPTIONS] <ID> <KEY>
```

```text
Arguments:
  <ID>
          The application's id

  <KEY>
          The file field's key

Options:
  -O, --out <PATH>
          Where to save it [default: the name it was uploaded with, here]
```

## `almena application credential-status`

Give an issued credential a new status (the issuer's signer signs its status list from their
wallet); revoking is final

```text
Usage: almena application credential-status [OPTIONS] <ID> <STATUS>
```

```text
Arguments:
  <ID>
          Its id

  <STATUS>
          The new status

          Possible values:
          - valid:     Valid again, after a suspension
          - suspended: Refused by verifiers until it is valid again
          - revoked:   Refused by verifiers for good
```
