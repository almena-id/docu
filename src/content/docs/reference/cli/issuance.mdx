Issuing an accepted application's credential

- [`issuance get`](#almena-issuance-get) — The credential to issue: its claims, proposed from the application
- [`issuance set`](#almena-issuance-set) — Settle the claims and validity (the issuer's signer); unset ones keep what is proposed
- [`issuance sign`](#almena-issuance-sign) — Sign the settled credential from your wallet: the application is then issued


```text

  <APPLICATION>
          The application's id
```

## `almena issuance set`

Settle the claims and validity (the issuer's signer); unset ones keep what is proposed

```text
Usage: almena issuance set [OPTIONS] <APPLICATION>
```

```text
Arguments:
  <APPLICATION>
          The application's id

Options:
      --file <FILE>
          The claims as a JSON object (`-` for stdin)

      --claim <CLAIM=VALUE>
          One claim, CLAIM=VALUE (VALUE read as JSON when it is, else as text); repeat for more

      --valid-until <DATE>
          The last day it is valid (YYYY-MM-DD, after today)
```
