```text

```

```text
Options:
      --limit <LIMIT>
          Items per page (1–100)
          
          [default: 20]

      --cursor <CURSOR>
          Start after this cursor (a page's `next_cursor`)

      --all
          Follow `next_cursor` until the last page

      --search <TEXT>
          Only those whose name (any case) or DID has this in it

      --grants <TYPE>
          Only those that grant this credential type
```

## `almena catalog offers`

Every published issuer's offers: a credential type it grants on request

```text
Usage: almena catalog offers [OPTIONS]
```

```text
Options:
      --limit <LIMIT>
          Items per page (1–100)
          
          [default: 20]

      --cursor <CURSOR>
          Start after this cursor (a page's `next_cursor`)

      --all
          Follow `next_cursor` until the last page

      --query <WORDS>
          Only those with every word in the type's names, descriptions or category, or the issuer's
          name or description

      --category <ID>
          Only those filed under this credential category (see `almena catalog offer-categories`)
```
