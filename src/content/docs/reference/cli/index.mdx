Command-line client of the Almena ID platform. This reference is read from the binary itself (`almena 0.1.0`): what each command says when asked for `--help`.

Install it and make your first call with the [quick start](/integrate/quick-start/).

## Options for every command

```text
Options:
  -v, --verbose
          Print more detail about what the command is doing
          
          [env: ALMENA_VERBOSE=]

      --profile <PROFILE>
          Configuration profile: its settings and its sign-in
          
          [env: ALMENA_PROFILE=]
          [default: default]

      --api-url <URL>
          The Almena API [default: https://api.almena.id]
          
          [env: ALMENA_API_URL=]

      --agent-url <URL>
          The Almena agent [default: https://agent.almena.id]
          
          [env: ALMENA_AGENT_URL=]

      --tenant <TENANT>
          Tenant to work in, by id or name [default: the profile's, or your only one]
          
          [env: ALMENA_TENANT=]

  -o, --output <OUTPUT>
          How results are printed [default: table]

          Possible values:
          - table: Human-readable tables
          - json:  The API's answer, as it came
          
          [env: ALMENA_OUTPUT=]

      --locale <LOCALE>
          Language of emails, of the wallet's sheet and of texts shown [default: en]
          
          [env: ALMENA_LOCALE=]
          [possible values: en, es]

  -y, --yes
          Answer yes to every confirmation

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version
```
