## `almena value-domain create`

Add one, from a JSON file (`{key, labels, source, codes}`), flags over it

```text
Usage: almena value-domain create [OPTIONS]
```

```text
Options:
      --file <FILE>
          The value list as JSON (`-` for stdin); `codes` is `[{value, labels, media_type?}]`

      --key <KEY>
          Its key (`[a-z][a-z0-9_]*`)

      --label <LANG=TEXT>
          Its name in a language, LANG=TEXT; one per language of the portal

      --source <SOURCE>
          The standard or list it comes from
```

## `almena value-domain update`

Change one: only what is passed; `codes` in the file replaces the whole list (while a field draws on
it, every code it had must stay)

```text
Usage: almena value-domain update [OPTIONS] <ID>
```

```text
Arguments:
  <ID>
          Its id

Options:
      --file <FILE>
          What changes, as JSON (`-` for stdin)

      --label <LANG=TEXT>
          Its name in a language, LANG=TEXT; one per language of the portal

      --source <SOURCE>
          The standard or list it comes from
```
