## `almena issuer create`

Register one (a draft until it is published)

```text
Usage: almena issuer create [OPTIONS] --name <NAME>
```

```text
Options:
      --name <NAME>
          Its name (1–200 characters)

      --description <LANG=TEXT>
          What it is for, in a language, LANG=TEXT; repeat per language

      --mediator <MEDIATOR>
          The mediator it receives messages through (see `almena mediator choices`)
```

## `almena issuer update`

Change its name, description or mediator; its DID stays

```text
Usage: almena issuer update [OPTIONS] <ID>
```

```text
Arguments:
  <ID>
          Its id

Options:
      --name <NAME>
          Its new name

      --description <LANG=TEXT>
          Its new description in a language, LANG=TEXT; repeat per language (the whole description:
          languages left out are dropped)

      --no-description
          Remove its description

      --mediator <MEDIATOR>
          Its new mediator

      --no-mediator
          Remove its mediator
```

## `almena issuer credential-types`


### `almena issuer credential-types get`

Show the types it grants, and their forms


```text
Arguments:
  <ID>
          The issuer's id
```

### `almena issuer credential-types set`

Declare the types it grants (replaces the list)

```text
Usage: almena issuer credential-types set [OPTIONS] <ID>
```

```text
Arguments:
  <ID>
          The issuer's id

Options:
      --type <TYPE>
          A credential type it grants (see `almena catalog credentials`); repeat for more

      --form <TYPE=FORM_ID>
          TYPE=FORM_ID: the form a type is applied for with, which makes it an offer
```

### `almena issuer status-list list`



### `almena issuer status-list sign`

Sign a status list as it is from your wallet (the issuer's signer): before its first credential, or
after the key it was signed with left the issuer's DID

```text
Usage: almena issuer status-list sign [OPTIONS] <ID>
```

```text
Arguments:
  <ID>
          The issuer's id

Options:
      --status-list <ID>
          The list to sign [default: its current one, made if it has none]
```
