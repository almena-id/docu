API tokens for scripts and CI

- [`token list`](#almena-token-list) — List your API tokens (never their secrets)
- [`token create`](#almena-token-create) — Make an API token; its secret is printed this once
- [`token delete`](#almena-token-delete) — Revoke an API token

## `almena token list`

List your API tokens (never their secrets)

```text
Usage: almena token list [OPTIONS]
```

## `almena token create`

Make an API token; its secret is printed this once

```text
Usage: almena token create [OPTIONS] --name <NAME>
```

```text
Options:
      --name <NAME>
          What it is for (up to 100 characters)

      --days <DAYS>
          Days it lasts (1–365)
          
          [default: 90]
```

## `almena token delete`

Revoke an API token

```text
Usage: almena token delete [OPTIONS] <ID>
```

```text
Arguments:
  <ID>
          The token's id
```
