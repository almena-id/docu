## `almena config set`

Set one of the profile's settings

```text
Usage: almena config set [OPTIONS] <KEY> <VALUE>
```

```text
Arguments:
  <KEY>
          The setting

          Possible values:
          - api-url:   The Almena API
          - agent-url: The Almena agent
          - tenant:    The tenant to work in, by id (`almena tenant use` sets it by name too)
          - output:    `table` or `json`
          - locale:    `en` or `es`

  <VALUE>
          Its value
```
