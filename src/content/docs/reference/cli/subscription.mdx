## `almena subscription set`

The trust anchor's admins: set an account's subscription

```text
Usage: almena subscription set [OPTIONS] --status <STATUS> <ACCOUNT>
```

```text
Arguments:
  <ACCOUNT>
          The account's id

Options:
      --status <STATUS>
          Where it stands
          
          [possible values: active, past-due, canceled]

      --plan <PLAN>
          Its plan
          
          [default: standard]

      --until <WHEN>
          Paid through this moment (RFC 3339, e.g. 2026-12-31T23:59:59Z); none: open-ended

      --note <NOTE>
          A note only the anchor reads (an invoice, an agreement)
```
