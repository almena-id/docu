## `almena verifier create`

Register one (a draft until it is published)

```text
Usage: almena verifier create [OPTIONS] --name <NAME>
```

```text
Options:
      --name <NAME>
          Its name (1–200 characters)

      --description <LANG=TEXT>
          What it is for, in a language, LANG=TEXT; repeat per language

      --mediator <MEDIATOR>
          The mediator it receives messages through (see `almena mediator choices`)
```

## `almena verifier update`

Change its name, description or mediator; its DID stays

```text
Usage: almena verifier update [OPTIONS] <ID>
```

```text
Arguments:
  <ID>
          Its id

Options:
      --name <NAME>
          Its new name

      --description <LANG=TEXT>
          Its new description in a language, LANG=TEXT; repeat per language (the whole description:
          languages left out are dropped)

      --no-description
          Remove its description

      --mediator <MEDIATOR>
          Its new mediator

      --no-mediator
          Remove its mediator
```
