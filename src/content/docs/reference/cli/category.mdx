## `almena category create`

Add one

```text
Usage: almena category create [OPTIONS] --kind <KIND> --key <KEY> --label <LANG=TEXT>
```

```text
Options:
      --kind <KIND>
          What it files
          
          [possible values: field, credential]

      --key <KEY>
          Its key (`[a-z][a-z0-9_]*`), once per kind

      --label <LANG=TEXT>
          Its name in a language, LANG=TEXT; one per language of the portal

      --icon <ICON>
          What it is drawn with (`tag`, `id-card`, `graduation-cap`…); the API's default when left
          out
```

## `almena category update`

Rename one or change its icon; its kind and key never change

```text
Usage: almena category update [OPTIONS] --label <LANG=TEXT> <ID>
```

```text
Arguments:
  <ID>
          Its id

Options:
      --label <LANG=TEXT>
          Its name in a language, LANG=TEXT; one per language of the portal

      --icon <ICON>
          What it is drawn with (`tag`, `id-card`, `graduation-cap`…); kept when left out
```
