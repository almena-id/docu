## `almena credential-type create`

Add a credential type (the anchor's: to Almena's catalogue), from flags, a JSON file, or both (flags
win)

```text
Usage: almena credential-type create [OPTIONS]
```

```text
Options:
      --key <KEY>
          Its key (`[a-z][a-z0-9_]*`); it names its `vct`

      --file <FILE>
          The type as JSON (`-` for stdin)

      --label <LANG=TEXT>
          Its name in a language, LANG=TEXT; repeat per language

      --description <LANG=TEXT>
          What it states, in a language, LANG=TEXT; repeat per language

      --category <CATEGORY>
          One of the catalogue's credential categories

      --source <SOURCE>
          The standard or model it follows

      --claim <FIELD>
          A field of the catalogue it always carries; repeat for more

      --optional-claim <FIELD>
          A field of the catalogue it may carry; repeat for more

      --issuance <ISSUANCE>
          Who issues it

          Possible values:
          - almena:   Any tenant's issuer grants it
          - external: Issued under a framework of its own; only asked for

      --vct <VCT>
          `external` types: how their framework names them

      --w3c-type <W3C_TYPE>
          Its W3C type, as in `VerifiableCredential` lists

      --mdoc-doctype <MDOC_DOCTYPE>
          Its mdoc doctype
```
