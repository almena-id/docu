# Contributing

Thanks for helping with the Almena Network documentation. By taking part you
agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md). Security issues go
through [SECURITY.md](SECURITY.md), never through public issues.

## Getting started

You need Node.js 24 or later, [pnpm](https://pnpm.io),
[Task](https://taskfile.dev) and Docker.

```bash
task init    # creates .env from .env.example
task dev     # runs the site with hot reload
task build   # the static site in dist/
task up      # the production build in Docker
task --list  # everything else
```

## Making a change

- Open an issue first for anything larger than a fix to a page, so the
  approach can be agreed before the writing.
- Everything is written in English (code, comments, docs, commit messages),
  except the site's own Spanish pages.
- Pages live in `src/content/docs/` (English) and `src/content/docs/es/`
  (Spanish), with the same file name in both; add each new one to the
  sidebar in `astro.config.mjs`, with its Spanish label in `translations`,
  unless its section is autogenerated.
- The documentation follows the platform specification (`spec`): where they
  disagree, the specification wins; open an issue rather than documenting the
  difference.
- This is Astro 7 with Starlight: read the relevant guide linked from
  [AGENTS.md](AGENTS.md) before relying on what you know of older versions.
- Never load anything from a third-party host in the visitor's browser: fonts,
  images and scripts are served from the site itself.
- Before sending a change, `task check` must pass: a production build.

## Pull requests

Keep a pull request to one topic, describe what it changes and why (with a
screenshot for visible changes, in light and dark), and link the issue it
addresses. By contributing you agree that your contribution is licensed under
the [Apache License 2.0](LICENSE), as the rest of the project.
